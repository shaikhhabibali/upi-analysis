# UPI Digital Payments in India: Growth, Seasonality & Forecast

An end-to-end data analytics project analysing India's UPI digital payment ecosystem using Python, SQL and Power BI.

## Project Objective

This project studies UPI transaction growth, seasonality, average ticket size, app-wise trends and future transaction patterns using official data sources.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Power BI
- JupyterLab
- Git & GitHub
